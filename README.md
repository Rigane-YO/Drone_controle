## Description
Ce projet est un simulateur de routage de drones naviguant à travers un réseau de zones interconnectées. L'objectif est d'acheminer une flotte de drones d'un point de départ à un point d'arrivée en un minimum de tours, tout en respectant des contraintes strictes de capacité et de mouvement.

## Instructions
- Installation : `make install`
- Exécution : `make run ARGS="maps/map_easy.txt"`
- Linter : `make lint`
